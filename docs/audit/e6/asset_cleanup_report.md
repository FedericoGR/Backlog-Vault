# Asset and resource cleanup report

Audited on 2026-07-19 from Git paths, `pubspec.yaml`, source references,
SHA-256 hashes, Android resources, Windows resources, and APK/Release contents.

## Inventory

- `assets/` does not exist and `pubspec.yaml` declares no custom runtime asset
  directory or font.
- Android has five density-specific launcher PNG files, totaling 4,181 bytes.
- Windows has one application ICO file, 33,772 bytes.
- Test JSON fixtures are under `test/`, are consumed by provider/parser tests,
  and are not packaged in release artifacts.
- Flutter supplies runtime ICU data, shaders, notices, manifests, and Material
  Icons during build. They are generated runtime files, not source assets.
- There are no splash assets, seeds, templates, Sync/backup runtime fixtures,
  bundled covers, or media files.

SHA-256 comparison found no exact duplicate among the launcher images, icon,
or JSON fixtures. Density variants are not duplicates: Android selects them by
device density. The ICO is the documented Windows runner icon and is required
to produce the executable resource.

## Package evidence

The universal APK's Flutter assets total 167,245 bytes uncompressed and include
only generated manifests, notices, two Flutter shaders, and the 12,644-byte
tree-shaken Material font. Android resources total 220,783 bytes uncompressed.
No user cover, scanner model, QR image, barcode model, Sync payload, or backup
fixture is present.

The Windows release contains the generated 1,645,184-byte Material font.
Unlike Android, the current Windows build does not tree-shake that font; it is
runtime output generated by Flutter and is retained because manually deleting
it would make the package incomplete.

## Decision

Assets removed: zero. Every source visual resource has a platform consumer and
all remaining JSON fixtures have tests. Re-encoding the tiny launcher resources
would risk quality/metadata for negligible benefit. No user/AppData media was
read, modified, copied, or deleted.
