# Backlog Vault UX copy glossary

Use these terms consistently in ARB catalogs and documentation.

| Concept | English | Español | Usage note |
|---|---|---|---|
| Library | Library | Biblioteca | The user's complete local collection. |
| Game | Game | Juego | Work-level videogame data, separate from personal data. |
| Library entry | Library entry | Entrada de biblioteca | The user's relationship/status/notes for a game; avoid in casual copy when “game” is clear. |
| Playthrough | Playthrough | Partida | One concrete run with dates, hours, rating and notes. |
| Status | Status | Estado | Library or playthrough lifecycle; qualify when ambiguous. |
| Platform | Platform | Plataforma | Catalog value such as PC or PlayStation. |
| Genre | Genre | Género | Catalog classification. |
| Metadata | Metadata | Metadata | Optional descriptive game information from RAWG/IGDB. |
| Cover | Cover | Portada | Selected local or provider-sourced cover image. “Cover art” may remain in provider-specific option labels. |
| Import | Import | Importación | CSV creates library data after mapping and preview. |
| Export | Export | Exportación | JSON writes a readable snapshot; never call it backup/restore. |
| Saved view | Saved view | Vista guardada | Persisted library filters, sort and columns. |
| Provider | Provider | Proveedor | Optional external metadata/media service. Provider proper names are unchanged. |
| Match | Match | Match/coincidencia | Existing product copy uses “match” in Spanish bulk review; do not imply automatic certainty. |

Use sentence case. Actions should be verbs (“Save”, “Retry”, “Export library”).
Errors explain what failed without exception types, stack traces, secrets or
paths. Success copy describes one completed action. Cancellation is neutral.
