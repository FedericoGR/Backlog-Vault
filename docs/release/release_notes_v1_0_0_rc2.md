# Backlog Vault v1.0.0-rc2

This release candidate packages the finalized personal game-log experience for
Windows and Android.

- Annual personal game log with completion-date ordering and simple filters.
- Simplified personal game records and redesigned yearly statistics.
- Portable Windows storage and improved edit persistence.
- Final Backlog Vault application icon.

The Android APK is locally debug-signed for personal testing and is not a Play
Store package.
